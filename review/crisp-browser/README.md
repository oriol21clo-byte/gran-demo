# Чёткая браузерная подача — возврат к ориентиру пользователя

База main: 16ad3ed7fff69ab0bb529692248e6e54fc17f4fc. Эта ветка создана заново от main: отвергнутые Blender-рендеры и предыдущие экспериментальные страницы в неё не входят.

`index.html` и `comparison.png` показывают три пары:

1. **Контрольный Three.js** — вариант «Серебро и графит» с присланного пользователем изображения; чёткая геометрия, градиент, оригинальные фасады и мягкие тени.
2. **Мягкий архитектурный свет, Three.js** — немного светлее день, спокойнее emissive ночью, умеренно более читаемая тень. Основная рекомендация для продолжения без смены визуального языка.
3. **Babylon.js 9.35.0** — реальный альтернативный браузерный движок: та же геометрия, сопоставимая ортографическая камера, отдельные инстансы светящихся окон, градиент и тени. Результат не объявлен лучше исходного; смена движка сама по себе качества не гарантирует. Распределение окон и параметры освещения между движками различаются, это сравнение художественных вариантов, не точный benchmark.

Все PNG — захваты WebGL canvas, без Cycles, внешнего denoise, bloom, дорисовок или генеративных изображений. Дневная и ночная геометрия одинаковая. Снимки Three.js используют текущие Viewer, GranVisual и Three.js r128 из production. Babylon строит ту же модель из сохранённого snapshot 11 561 mesh-инстанса, 43 геометрий и 25 материалов. Размеры по-прежнему оценочные.

## Проверки

Chromium / SwiftShader: все шесть финальных состояний получены, ошибок JavaScript не зафиксировано. Babylon дополнительно исправлен после визуальной проверки: цветовое пространство материалов, прозрачность тени, направление градиента. Все финальные изображения осмотрены. Автоанимация отключена для процедуры захвата. Проверка не измеряет реальный GPU FPS. Мобильные и остальные проекты в этом проходе не проверялись. Внешние шрифты отключены при проверке, использованы системные.

После переноса review на чистую ветку пути локальных зависимостей изменены; сами отрисованные функции и геометрия не менялись. Не используется код/ассеты из отвергнутого Blender-варианта: model.json.gz — исходная геометрия сайта, не результат обработки в Blender.

## Воспроизведение

Сервер из корня репозитория: `python3 -m http.server 8000`.

- `/review/crisp-browser/three.html` — оригинал/мягкий свет, день/ночь.
- `/review/crisp-browser/babylon.html` — Babylon.js, день/ночь.
- `node review/crisp-browser/render.cjs` — получить кадры (нужны Playwright и Chromium `/usr/bin/chromium`).

Зависимости сборки Babylon из корня:

```
npm install --prefix work/babylon --cache work/npm-cache --no-audit --no-fund @babylonjs/core@9.35.0 @babylonjs/materials@9.35.0 esbuild@0.28.2
work/babylon/node_modules/.bin/esbuild review/crisp-browser/babylon-source.js --bundle --minify --format=esm --outfile=review/crisp-browser/babylon.bundle.js --legal-comments=eof
```

Готовый bundle включён только для автономности review; production сайт его не загружает. Babylon.js лицензирован Apache-2.0, LICENSE/NOTICE приложены.
