# Направление ступенчатых башен проекта 3

Исправление относительно публикации `ac931abafe9dabbaf3760292d895b46fdebee812`.
На присланном пользователем уличном ракурсе высокие края находятся снаружи двух кварталов, а кровли понижаются к центральному проходу. Ранее направление было обратным.

Изменён знак направления в вызове построения обеих башен. Их положения, габариты в плане, высота, дворы и остальные корпуса сохранены. Расчёт окон верхних этажей использует то же направление, что и геометрия кровель.

Проверка tests/geometry.cjs направляет лучи вниз на наружные и внутренние части обеих кровель: наружные края должны быть выше внутренних более чем на 8 м. Проверка падает на предыдущей геометрии и проходит после исправления. `npm test` проходит.

`browser.cjs` снимает предыдущую и исправленную геометрию одним Three.js-рендерером с одинаковой камерой. Для «до» подменяется только направление башен локальным перехватом ресурса, опубликованный сайт не меняется. `before.jpg`, `after.jpg`, `night.jpg` — кадры canvas.

Изменение подготовлено в отдельной ветке. Публикация этой исправленной версии требует согласования.
