# Blender → Three.js: световые исследования ГРАНЬ

Это реальные рендеры Blender 4.3.2 / Cycles, не сгенерированные иллюстрации. Исходная геометрия первого проекта извлечена из `GranReference.build` и spec текущего index.html: 11 561 mesh-инстанс, 43 исходные геометрии, 25 материалов. Размеры остаются оценочными, как и в модели сайта. Дизайн страницы и геометрия зданий не менялись.

## Что смотреть

- `index.html` — три пары Blender и отдельное браузерное сопоставление.
- `1-day.png`, `1-night.png` — минеральный свет (рекомендуемый нейтральный вариант).
- `2-day.png`, `2-night.png` — тёплая архитектура.
- `3-day.png`, `3-night.png` — контрастная галерея.
- `three-day.png`, `three-night.png` — реальные кадры Three.js; **не выдавать рендеры Blender за результат браузера**.
- `gran-lighting.blend` — редактируемая сцена; сохранена в последнем ночном состоянии.

## Blender

Cycles CPU, 1200×900, 64 samples, AgX Medium High Contrast. Без HDRI/сторонних ассетов. Физические тени, отражения и непрямой свет; area lights на фасадах, шесть небольших источников в зоне благоустройства. Окна разделены по инстансам: примерно 62% тёмных, 25% тёплых и 13% менее ярких. Распределение детерминированное. Реальные интерьеры не моделировались, окна — отражающие панели с emissive-материалом ночью.

В сборке Blender отключена поддержка встроенного OpenImageDenoise. Поэтому после расчёта применён официальный Intel Open Image Denoise 2.5.1 CPU (RT high, LDR sRGB) для удаления шума. Геометрия и композиция им не менялись. Это не дополнительный генеративный рисунок. На мелких деталях возможно сглаживание.

## Браузерное сопоставление

`browser.html` работает через HTTP, загружает настоящий Viewer сайта в iframe. В `browser-match.js` добавлены:

- небольшая градиентная текстура фона;
- параметры стекла;
- отдельная `InstancedBufferAttribute` occupancy для светящихся окон и минимальное изменение шейдера emissive;
- направление камеры, согласованное со сценой Blender;
- существующее освещение/прожекторы из предыдущего review-прототипа.

Переотражения Cycles не перенесены в WebGL. Для дальнейшего сближения нужны запечённое освещение/окружение и отдельная проверка бюджета на мобильных. Перенос всей сцены с множеством реальных источников в браузер не предлагается. Готовые Blender-рендеры можно использовать как быстрые статичные карточки, а интерактивную модель оставить лёгкой.

## Воспроизведение

Из корня репозитория:

```
mkdir -p work/blender
node review/blender-studies/export.cjs
blender -b -noaudio -t 8 --factory-startup --python review/blender-studies/render.py
# Для одной пары:
blender -b -noaudio -t 8 --factory-startup --python review/blender-studies/render.py -- 1
```

`model.json.gz` содержит экспорт геометрии для воспроизводимости. Скрипт render.py читает его без необходимости запуска Node. Export.cjs сохраняет свежий исходный JSON в work/blender/model.json; перед пересборкой модели обновить сжатый snapshot.

Для denoise.py нужен numpy, Pillow и официальный binary `oidnDenoise` по пути work/blender/oidn-2.5.1.x86_64.linux/bin/oidnDenoise. Источник: https://github.com/RenderKit/oidn/releases/tag/v2.5.1. Он не включён в репозиторий. Сначала сохранить шумные рендеры для повторной обработки в work/, затем применить denoise.py к нужным PNG.

## Ограничения

Это предложения на одном проекте. Другие проекты, реальный GPU FPS и мобильное качество ещё не проверены. Production JS не подключает прототипы; на опубликованный сайт изменения не внесены. Ветка также содержит ранее подготовленные review-материалы и согласованное локальное усиление линий блока комплекта. Публикация только после явного согласования.

## Фактическая проверка

- Cycles: все шесть PNG успешно рассчитаны; сцена сохранена, 4 МБ.
- Chromium / SwiftShader: день и ночь захвачены из WebGL canvas; JS/shader errors не зафиксированы. Единственное сообщение console.error — ERR_CERT_AUTHORITY_INVALID при внешнем ресурсе; шрифты системные. Автоанимация в процедуре захвата остановлена, чтобы не перегружать программную графику; FPS этот тест не измеряет.
- Использован тот же Three.js r128, GranVisual и Viewer сайта; геометрия не подменяется.
- `comparison.png` содержит только Blender, `index.html` также показывает отдельную пару Three.js.
