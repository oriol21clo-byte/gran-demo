# Проект 3 — реконструкция по восьми изображениям

Основа: опубликованный main `5292fc96830f8b88ab0e3875628a22cbc28ce51a`. Публикация не разрешена.

## Что перенесено

- Два вытянутых периметральных квартала, развернутых друг к другу вдоль центрального пешеходного пространства, и два независимых продольных двора.
- Две тёмные пластинчатые башни с пятиступенчатым завершением, тёмные трёхэтажные основания и низкие замыкающие объёмы.
- Разноэтажные секции, ленточное остекление и отступающие венчания меньших башен, вертикальные фасадные рёбра, витринный первый этаж.
- Различные палитры: красно-розовая и мятно-белая, тёмные оконные рамы, плоские кровли и парапеты.
- Продольные мощёные проходы, красные извилистые дорожки, четыре игровые зоны в каждом дворе, деревья, цветники и скамьи.

Расположение восстановлено прежде всего по верхнему ракурсу; силуэт — по двум внешним и общему виду. Дворы сверены по двум встречным ракурсам. Геометрия, число этажей, размеры и скрытые стороны оценочные: фотографий недостаточно для обмерной точности. Максимальная высота 99,45 м принята из существующего паспорта проекта; другие опубликованные ТЭП и тексты не менялись.

## Проверка

`npm test`: цены, геометрия, DOM, WebGL fallback, жизненный цикл сцен и освещение всех проектов. Новая сцена: 308 768 треугольников, 38 instanced/обычных mesh; точный итог выводится tests/geometry.cjs. Геометрия конечна, бюджет менее 650 тыс. треугольников / 100 mesh. Разрешение рендера не снижено.

`node review/project-three-reference/browser.cjs`: реальные кадры Three.js при дневном / ночном свете, вид сверху, обратная сторона, двор и телефон 390×844. Ошибки JavaScript и горизонтальное переполнение проверяются сценарием. Автовращение в рабочем просмотрщике и карточках сохранено; для снимков камера остановлена. Кадры PNG экспортированы из того же WebGL canvas без интерфейсных наложений.

Проверки CPU не подтверждают визуальную точность. Кадры следует сравнивать с исходными изображениями; скрытая геометрия и метрические размеры остаются реконструкцией. FPS на устройстве пользователя не измерен.
