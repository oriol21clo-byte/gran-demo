# Главный макет и качество моделей

Утренний опубликованный ориентир — 3ba82f9e6c09f5fdf92c093ed21ecfe99a947028. Архитектура и окружение главной сцены с тех пор не менялись. Возвращена освещаемая плоскость вместо плоского нетонируемого фона; её цвет немного темнее утреннего: #BFC1C0 вместо #C5C7C6. Сохранены корпуса окружения, дороги, автомобили, деревья, освещение и три режима. Второй слой теней отключён, чтобы не удваивать тени. Фон карточек не меняется.

Проект 1: полное функциональное название из сообщения, адрес «ул. Ав***ая», СПП в ГНС 71 136 м². Высота и участок остаются «—» до подтверждения.

Проект 2: по ранее присланным фотографиям уменьшена доля стекла коричневого крыла, расширены кирпичные простенки, добавлены непрозрачные подоконные панели, снята лишняя верхняя перемычка коричневых окон. Белые многослойные порталы, кровля, стилобат, посадки и оборудование сохранены. Объёмная детализация не сокращалась; точность обмерной модели не заявляется. Новый PDF по-прежнему недоступен из-за лимита передачи 32 MiB.

Все сцены: увеличено целевое сглаживание до 2x на настольных экранах / 1.75x на узких при прежнем ограничении числа пикселей. Antialias сохранён, запрошен high-performance WebGL. В скрытой вкладке рендер приостанавливается. Существующее медленное вращение через requestAnimationFrame и нормализация скорости по времени сохранены; искусственного ограничения 60 FPS нет. Рябь может зависеть от масштаба и устройства; устранение всех артефактов и 120 FPS не подтверждены замером. Монитор 60 Гц не показывает 120 разных кадров в секунду.

Полный npm test и git diff --check прошли: тарифы и коэффициенты, DOM, сцены, геометрия и сохранение окружения. Публикация не выполнялась.
