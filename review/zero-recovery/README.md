# Исправление нуля, запуск страницы и варианты палитры

Причина ошибки калькулятора: при площади 0 выражение `per / sqrt(per * 1.7)` превращалось в 0/0. NaN попадал в размеры участка, интерполяцию и камеру, и последующее увеличение площади не восстанавливало числовое состояние. Для визуального макета обеспечена конечная минимальная условная площадь; финансовый расчёт использует исходное значение 0 и показывает 0 ₽. Шкала 0–35 000 м² на первых 20% сохранена.

Регрессионный тест выполняет 0 → 35 000 → 0 → 12 000, ждёт завершения построения, прокручивает анимацию с шагом 1/120 секунды, проверяет конечные координаты участка/камеры/геометрии и видимость детальной модели. Это проверка логики, не замер FPS.

Первоначальная загрузка больше не загружает PDF-генератор; он подключается при скачивании КП. Четыре проектных WebGL-просмотрщика, геометрия и контексты создаются по IntersectionObserver при приближении к карточкам. Запас 180px уменьшает вероятность ожидания после прокрутки. Геометрия не упрощалась. При отсутствии IntersectionObserver используется прежняя немедленная инициализация. Скорость загрузки по сети и FPS на устройстве пользователя не измерены; количественный выигрыш не заявляется.

Каждое новое открытие страницы сбрасывает начальный якорь и восстановление старой позиции прокрутки, чтобы начинать с главного экрана. Последующие переходы по разделам внутри страницы работают штатно. Намеренное поведение: внешняя ссылка #calc тоже начинает с главного экрана по просьбе пользователя.

Палитры находятся в review/palettes/index.html: пять сравнимых карточек и интерактивное применение выбранной палитры к изолированному iframe страницы. Изменяются цвета интерфейса; геометрия и материалы 3D не меняются. Переключение палитр не записывается в основной сайт. Это варианты для выбора, а не утверждённый редизайн.

Модели сверены с доступными альбомами и фотографиями; ограничения и список недостающих файлов — MODEL-AUDIT.md. Точного совпадения «1 в 1» сейчас нет. Текущая геометрия в этой правке не менялась.

Полный npm test и git diff --check; реальный Chromium ANGLE SwiftShader: открытие с #calc приводит на главный экран; проверены 0 и последующее увеличение площади. Локальный QA-стенд использует Three.js/OrbitControls из node_modules; исходная страница сохраняет CDN-ссылки. Публикация не выполнялась.
