# Задняя полуовальная часть второго проекта

Основа: aaedae41ee0d6d20222cb59a5a03b20f84cc7d2a. Добавляется только ко второй карточке, ул. Баб****ая. Полный SHA версии указан в PR.

По шести новым архитектурным фотографиям снаружи задней коричневой плоскости добавлен полуовальный объём. Он включает светлые поэтажные плиты, заглублённое остекление лоджий, прозрачные ограждения, тонкие светлые профили и парные бронзовые стойки, смещающиеся через этаж. Добавлены разделительные стенки лоджий и остеклённое основание с бронзовым поясом. Пояса привязаны к существующим этажам и высоте готовой модели; размеры и скрытые детали оценочные. По уточнению пользователя выступ полуовала увеличен на 25% относительно первого варианта 60e3593438411effeef4c9f8d6d8a17dea41b5f8: глубина меняется относительно плоскости примыкания, ширина вдоль фасада и высота сохранены. Вместе увеличены только задний каркас, остекление и его основание.

Белый лицевой объём, его оконные порталы, верхние тёмные секции, коричневая пластина и передний стилобат сохранены. Дополнение находится у задней плоскости X≈7,2 и выше не выходит за прежнюю отметку. На существующей территории подавлены только растения и мебель, которые попадали внутрь новой части; последовательность случайного размещения оставшихся посадок сохранена. Небольшая площадка под пристройкой добавлена только сзади. Сверху новая кровля закономерно видна за прежним парапетом; это часть добавленного заднего объёма.

Тексты, показатели, калькулятор, остальные проекты, штатная камера, разрешение и вращение не менялись. Новые повторяющиеся детали инстансированы. Проект 2: 260 457 треугольников, 81 mesh против 215 075 / 67 до дополнения. Это счётчики сцены, не измерение FPS на компьютере пользователя.

## Проверки

На первом варианте прошёл npm test: цены, геометрия, DOM, сценарий без WebGL и жизненный цикл сцен. После увеличения глубины повторно пройдены tests/geometry.cjs и tests/scenes.cjs, а также проверка в Chromium. Проверяются полуовальная выпуклость, реальные границы дополнения с учётом матриц инстансов и совпадение пересечений двенадцати лицевых лучей с опубликованной моделью. Контрольные лучи и SHA исходного модуля сохранены в front-baseline.json. В Chromium нет ошибок JavaScript и переполнения при 390 px.
