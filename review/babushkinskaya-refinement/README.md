# Второй проект — лёгкий разворот фасада и ландшафт по фото

Основа публикации: cda1dd62a7f264b2f23b8900a605ac57239e6ac4. Вторая карточка, ул. Баб****ая; третий проект не заменяется. Кадры и проверки относятся к коммиту, содержащему этот файл; полный SHA указан в PR #28.

По приоритетному виду сверху перестроены тонкая коричневая пластина с длинной узкой кровлей, выступающий центральный технический объём, поднятое белое П-образное обрамление, сплошные тёмные боковые стены верхнего объёма (тот же материал, что соседние тёмные секции) и четыре широкие тёмные секции вдоль коричневого фасада. Между ними — узкие остеклённые щели; перед ними — открытая клиновидная кровля. Белый передний фасад состоит из трёх неглубоких граней, которые дают лёгкий выпуклый разворот в плане. Шесть широких оконных осей и глубокие порталы через три этажа следуют граням. Четыре верхние тёмные секции развёрнуты небольшим веером; коричневый задний корпус остаётся прямым и вертикальным. Кровля башни повторяет новый контур; нижний объём имеет отдельный прямолинейный план. Нижний кирпичный объём имеет одну прямую переднюю стену. Слева кровля выступает над отступающей стеной; только правый угол имеет небольшое локальное скругление. Передняя кромка кровли наклонена по видимым концам на исходном виде сверху (примерно 103,328 и 235,416 в изображении 432×525). На фронте четыре вертикальных кирпичных выступа по крупному фото. Белый корпус начинается над нижним объёмом, без перекрывающего кирпичную стену белого цоколя. Масштаб кладки нижней части уменьшен, тон затемнён по крупному фото; белые камни перенесены на свободную площадку перед стеной.

Ландшафт приближен к видимому рисунку на фото: асимметричный участок с боковым уступом, диагональные цветники, широкие проходы и швы мощения. Павильон с подвесными кольцами смещён к боковой площадке, рядом добавлено небольшое покрытие с круглыми элементами. Посадки мельче и плотнее, деревья и мебель расставлены вдоль проходов. Закрывающие стены верхней части остаются тёмными.

Тексты, показатели, остальные проекты, штатная камера, освещение, вращение и разрешение сайта сохранены. Размеры и скрытые детали восстановлены оценочно по фотографиям; обмерная точность не заявляется.

## Кадры

Все изображения получены реальным Three.js-рендерером сайта, без генеративной дорисовки.

- white.jpg, brown.jpg, roof.jpg, detail.jpg, night.jpg — модель в штатной ортографической камере сайта, дополнительные ракурсы и ночь.
- podium-top.jpg — нижняя часть с той же перспективной камерой, что reference-view.jpg, с уменьшенным полем кадра; для проверки очертания кровли.
- podium.jpg — близкий ракурс выступающего кирпичного объёма со стороны площадки и навеса.
- reference-view.jpg — та же модель и материалы с отдельной перспективной камерой, подобранной по видимым точкам исходного снимка, и нейтральным фоном. Это ракурс для сопоставления; штатная камера и фон сайта не менялись. Невидимые в исходнике размеры и ландшафт не являются точной копией.
- before-white.jpg, before-brown.jpg, before-roof.jpg — опубликованная модель до всей доработки.

## Проверки и воспроизведение

npm test проходит: геометрия, навигация, калькулятор, проектный просмотрщик, резервный режим при недоступном WebGL и жизненный цикл сцен. Геометрические лучи проверяют толщину коричневого корпуса, четыре верхних секции, поднятое белое обрамление, выступ технического объёма, закрытые торцы верхнего этажа с обеих сторон, свободную клиновидную кровлю направление фасада, разные нормали его трёх граней и наличие крыши/стены нижнего объёма, прямолинейность его фронта и отступ левой стены под кровлей. Второй проект: 215 075 треугольников, 67 mesh. Сохранён бюджет менее 300 000 треугольников и 100 mesh. Это счётчики геометрии, не измерение FPS на компьютере пользователя.

В Chromium сняты дневные и ночной ракурсы; ошибок JavaScript и переполнения при ширине 390 px нет. Playwright и Chromium нужны только для воспроизведения снимков, не для работы сайта. Запустить статический сервер из корня репозитория на порту 8052, затем node review/babushkinskaya-refinement/browser.cjs и node review/babushkinskaya-refinement/reference-view.cjs. Другой адрес задаётся через GRAN_REVIEW_URL. Параметры перспективной камеры — reference-camera.json.

Изменения подготовлены в PR для согласования. Публичный сайт не изменён.
