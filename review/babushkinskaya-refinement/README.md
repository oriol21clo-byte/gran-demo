# Второй проект — уточнение по приоритетному виду сверху

Основа публикации: cda1dd62a7f264b2f23b8900a605ac57239e6ac4. Вторая карточка, ул. Баб****ая; третий проект не заменяется.

Коричневая часть сужена до тонкой пластины: её кровля — длинная узкая полоса, как на приоритетном изображении. Белое крыло имеет диагональную переднюю плоскость по всей длине, а не прямоугольный план с небольшим срезанным уголком. Над ним — четыре широкие тёмные вертикальные части в одном ряду вдоль длинного коричневого фасада (ось Z), с узкими остеклёнными промежутками. Перед ними оставлена открытая клиновидная кровля. Наклон контура сверяется с последним изображением пользователя: ближний выступ белого крыла находится у положительного конца Z. Входы и диагональная часть стилобата следуют этому контуру.

Сохранены глубокие оконные порталы, верхние светлые пролёты коричневого фасада, парапеты и благоустройство. Тексты, паспорт и другие проекты, разрешение и вращение не менялись. Размеры, скрытые стороны и высоты остаются оценочными, без обмерной точности.

Проверка: npm test, включая лучи в четырёх верхних объёмах, проверку свободной клиновидной кровли и фактического направления диагонального фасада. Chromium: два общих ракурса, вид сверху с камерой напротив длинной стороны, крупный фасад и ночь, ошибки JS и мобильное переполнение. Все кадры — Three.js сайта. before-white.jpg — опубликованная исходная модель до всей доработки.
