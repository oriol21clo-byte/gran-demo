# Удаление формул из результата калькулятора

Убраны тарифы и множители из подписей трёх строк результата и поясняющий абзац с формулой/порогами площади. Полные названия моделей и их суммы, итог, срок и кнопка КП сохранены. Функция calcPrice, тарифы, коэффициенты и содержимое PDF не менялись. Сетка и остальные блоки сохранены.

Проверено: tests/pricing.cjs, tests/dom.cjs и tests/dom.cjs --webgl-blocked. Chromium: 1440 и 390 px, по три строки результата, без формул и горизонтального переполнения; ошибок JavaScript нет. Кадры desktop.png и mobile.png сняты с действующей страницы при площади 24 000 м² и стандартных параметрах. Полный SHA версии указан в PR.

Воспроизведение: статический сервер из корня на порту 8058, затем node review/calculator-cleanup/browser.cjs. Другой URL задаётся через GRAN_REVIEW_URL. Playwright/Chromium нужны только для воспроизведения кадров.

Изменения подготовлены для согласования, публикация не выполнялась.
