# Пять вариантов дня и ночи

Основа: опубликованный сайт 16ad3ed7fff69ab0bb529692248e6e54fc17f4fc и предыдущие материалы согласования 8caf298b46ce2e83e7c970cd7bd689d63d6958a1.

Блок состава комплекта сохранён. Единственная предлагаемая production-правка — цвет линий #bdc8d5 вместо #dce2e8: внешние горизонтальные, между колонками, под заголовками и над характеристиками. Толщина, отступы, сетка, содержание, кнопки сохранены. Мобильные разделители сохраняют прежнее расположение.

Открыть `compare.html` для пяти пар или `index.html` для интерактивного переключения.

1. **Серебро и графит** (рекомендуется): холодный светлый дневной фон и графитовый ночной, спокойная интеграция в существующий сайт.
2. **Небо и индиго**: голубое небо днём, глубокий синий ночью, более заметная атмосфера.
3. **Тёплый камень**: песочно-молочные дневные оттенки и дымчатый тёплый ночной фон, янтарные окна.
4. **Скандинавский свет**: рассеянный прохладный свет, сине-зелёная ночь с мягким контрастом.
5. **Архитектурная галерея**: более направленный дневной свет, почти чёрная ночь и яркие акценты окон.

Все пары сняты на одном проекте в одинаковом ракурсе текущим Three.js r128. Геометрия и материалы фасадов сохранены; в ночи меняются emissive-параметры окон, свет и фон. Градиент — небольшая CanvasTexture 256×512, создаётся один раз на вариант и кешируется. Без bloom/размытия/новых карт теней. Два унаследованных от предыдущего прототипа прожектора не отбрасывают тени. ShadowMaterial остаётся для контакта с поверхностью, сплошная дальняя плоскость скрыта, чтобы градиент был виден.

Окна в прототипе распределены по группам общих материалов; для естественного случайного рисунка в финале нужна отдельная маска инстансов. Освещение остальных проектов пока не настроено. Прототипы только в review/, код сайта их не подключает. Публикация не выполнялась.

Проверки: Chromium 1440×1050 с программной графикой, десять состояний; системные шрифты (внешние отключены в проверке). Реальный GPU FPS не измерялся. Команда генерации снимков сохранена в render.cjs; выполнять из корня репозитория при запущенном HTTP-сервере на 8000 и установленном Playwright/Chromium. Тестировать production-логику повторно не требовалось: изменён только цвет разделителей; прототипы проверены браузером.

Фактический результат проверки: JS errors — []; цвет разделителей rgb(189,200,213); 390 px — горизонтального переполнения нет. Все 10 снимков сохранены; comparison.png — обзор пяти пар. Проверки относятся к этой версии пресетов и CSS.
